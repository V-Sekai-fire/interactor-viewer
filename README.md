# weftfit/viewer  _(planned)_

Output **adapter** (a `mesh_sink`) for QA visualization of weftfit solver output —
an Elixir-bound Polyscope viewer (via Fine) that loads the retarget core's
per-step meshes to confirm intersection-free fits and no lost ngons/UVs/materials,
and to diff against OBJ references. Not yet implemented; scaffold only.
